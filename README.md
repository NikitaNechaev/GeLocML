# GeLocML
Решение задачи "Прогнозирование локализации белков E. coli с применением методов машинного обучения"

## Описание проекта

GeLocML - это приложение для прогнозирования локализации белков в клетке E. coli с использованием методов машинного обучения. 
Программа обучает модель на известных данных о локализации белков и затем может предсказывать локализацию для новых последовательностей.

## Установка

### Требования
- Python 3.8 или выше
- pip

### Установка из исходного кода
```bash
git clone https://github.com/username/GeLocML.git
cd GeLocML
pip install -e .
```

Это установит пакет в режиме разработки и создаст консольную команду `geloc`.

## Использование

Программа управляется через командную строку с использованием стандартных флагов.

### Основные режимы работы

GeLocML имеет четыре основных режима работы, которые являются взаимоисключающими (можно указать только один за раз):

1. **`--train`** - Запуск обучения модели
2. **`--predict`** - Запуск предсказания локализации белков
3. **`--evaluate`** - Оценка качества обученной модели
4. **`--version`** - Показать версию программы

Если ни один режим не указан, по умолчанию запускается обучение модели.

### Общие аргументы

Эти аргументы доступны во всех режимах:

- **`--data`** (строка, по умолчанию: `data/raw`)
  - Путь к директории с данными.
  - Пример: `--data /path/to/my/data`

- **`--model`** (строка, по умолчанию: `models/geloc_model.pkl`)
  - Путь к файлу модели.
  - При обучении: куда сохранить обученную модель.
  - При предсказании/оценке: откуда загрузить модель.
  - Пример: `--model /path/to/my/model.pkl`

- **`--output`** (строка, по умолчанию: `results/`)
  - Путь к выходной директории для сохранения результатов.
  - Пример: `--output /path/to/my/results`

- **`--config`** (строка, по умолчанию: не указан)
  - Путь к конфигурационному файлу (YAML/JSON).
  - Если не указан, используются значения по умолчанию.

- **`-v`, `--verbose`** (флаг)
  - Включить подробный вывод информации о процессе выполнения.

- **`-vv`, `--very-verbose`** (флаг)
  - Включить очень подробный вывод (включает все логи отладки).

### Аргументы для обучения (используются только с `--train`)

- **`--epochs`** (целое число, по умолчанию: `100`)
  - Количество эпох обучения.
  - Пример: `--epochs 50`

- **`--batch-size`** (целое число, по умолчанию: `32`)
  - Размер батча для обучения.
  - Пример: `--batch-size 64`

- **`--learning-rate`** (число с плавающей точкой, по умолчанию: `0.001`)
  - Скорость обучения (learning rate).
  - Пример: `--learning-rate 0.0001`

### Аргументы для предсказания (используются только с `--predict`)

- **`--input`** (строка, обязательный)
  - Путь к входному файлу для предсказания (например, FASTA файл с последовательностями белков).
  - Пример: `--input test.fasta`

- **`--threshold`** (число с плавающей точкой, по умолчанию: `0.5`)
  - Порог для классификации (значение от 0 до 1).
  - Пример: `--threshold 0.7`

## Примеры использования

### Обучение модели
```bash
# Обучение с использованием данных по умолчанию
geloc --train

# Обучение с указанием пути к данным и других параметров
geloc --train --data /path/to/data --epochs 50 --batch-size 64 --learning-rate 0.0001 --verbose
```

### Предсказание локализации
```bash
# Предсказание для нового файла с последовательностями
geloc --predict --model models/geloc_model.pkl --input test.fasta --output results/predictions

# Использование собственного порога классификации
geloc --predict --model model.pkl --input test.fasta --threshold 0.7
```

### Оценка модели
```bash
# Оценка качества модели на тестовых данных
geloc --evaluate --model models/geloc_model.pkl --data data/test/ --output results/evaluation
```

### Проверка версии и справки
```bash
# Показать версию программы
geloc --version

# Показать справку по использованию
geloc --help
```

## Как это работает

1. **Обучение (`--train`)**:
   - Загружает данные из указанной директории (файл `ecoli_data.txt`)
   - Создает и обучает модель машинного обучения (нейронную сеть или другой алгоритм)
   - Сохраняет обученную модель в указанный файл
   - Генерирует отчет об обучении с метриками качества

2. **Предсказание (`--predict`)**:
   - Загружает ранее обученную модель
   - Обрабатывает входной файл с последовательностями белков
   - Делает предсказание локализации для каждой последовательности
   - Сохраняет результаты в CSV файл

3. **Оценка (`--evaluate`)**:
   - Загружает модель и тестовые данные
   - Оценивает качество модели на тестовой выборке
   - Вычисляет метрики: accuracy, precision, recall, F1-score
   - Сохраняет результаты оценки

## Настройка через конфигурационный файл

Вместо указания всех параметров в командной строке можно использовать конфигурационный файл (YAML или JSON):

```yaml
data: /path/to/data
model: /path/to/model.pkl
output: /path/to/results
epochs: 100
batch-size: 32
learning-rate: 0.001
verbose: true
```

Затем запустите программу с указанием пути к конфигурационному файлу:
```bash
geloc --train --config config.yaml
```
